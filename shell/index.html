    库特别支持

    诊断

    点击输入框后直接按下要用的组合键即可录入（如按住 Ctrl 再按 0 得到 Ctrl+0）；Backspace 清除（留空表示解绑），Esc 撤销本次录入。 支持字母、数字、F1–F24 与 / - , . ; [ ] 等符号键。跳转定义的 F12 与 Ctrl+点击固定保留。

    保存行为

    整理导入 = 移除未使用的导入 + 按 isort 规则排序；手动触发见「快捷键 → Optimize Imports」。

    引擎与运行时

    开启后单步进入不会误入 site-packages / 标准库；改动需停止并重新启动调试会话生效。

    包管理

    诊断级别

    ruff 规则按首字母分类映射到编辑器波浪线级别；保存后立即生效（自动重查当前文件）。行内忽略见编辑器右键「忽略此规则」。

    数据库

    日志输出

    日志写入数据根的 logs/pylume.log，单文件超过 1 MiB 自动轮转。关闭「启用日志」后仍会记录错误级日志。

    目录

    数据位置

    可再生清理

    uv 缓存默认与其他项目通过硬链接共享；深度清理后已装环境不受影响，但重装包将重新落盘。uv 位置由用户自有环境变量（UV_CACHE_DIR 等）决定，Pylume 不代管。

    迁移

    迁移 = 复制数据到目标并写入数据根指针文件（位于系统配置目录，仅几十字节），重启后生效。uv 缓存/工具目录由你的环境变量（UV_CACHE_DIR / UV_TOOL_DIR）自行管理，Pylume 不代管。旧目录不会被自动删除，重启确认无误后可手工删除。
